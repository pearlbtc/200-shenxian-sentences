# 可以支撑你很久的200句神仙句子 · 在线学习小工具

拼多多店铺「壹页格物」配套 PWA 学习小工具，与同名电子书（A5 PDF）同源。

## 功能
- **神仙句库**：200 句按五卷（宽慰 / 定力 / 孤勇 / 释怀 / 微光）分类浏览、搜索、筛选。
- **学习**：每日一组随机推送，上/下条切换，一键收藏，🔊 央视风朗诵（edge-tts 预生成音频）。
- **收藏**：随手收进「我的收藏」，随时回看。
- **自测**：挖空填字，8 字以内留 1 空、超 8 字留 2 空；闯关晋级、错题回顾、过关奖励。
- **战绩**：学习轮次 / 已掌握条数 / 收藏数，localStorage 持久化。
- 离线缓存（Service Worker，音频不进 SW 以保流式播放）、微信内朗读提示。

## 数据源
- 唯一数据层：`data.js`（`window.ENTRIES` / `window.COLLECTIONS`），由项目根目录 `data.js`（window.BOOK）经 `build_pwa_data.js` 转换生成。
- 朗诵音频：`audio/1..200.mp3`，由 `生成脚本` edge-tts（zh-CN-YunyangNeural）生成。
- 卷首图 / 封面 / 图标：复用电子书 PDF 的 5 张水墨样图（samples/）。

## 本地预览
```
cd pwa
python -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123
```

## 发布注意（知行学习包铁律）
- 源数据（data.js / BOOK）一旦增删或重排词条，必须**全量重生成音频**并 `app.js` 里 `AUDIO_V` +1，否则「显示A读成B」。
- 每次发布：`index.html` 的 `?v=N`、`sw.js` 的 `CACHE` 版本号各 +1，破 GitHub Pages 10 分钟缓存。
- 多音字拼音未自动注音（v1），如需拼音须逐条人工核定后再加。
